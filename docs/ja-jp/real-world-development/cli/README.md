**[GitHub Copilot CLI][about-copilot-cli]** を使うと、GitHub Copilot をエージェント型コーディングアシスタントとしてターミナルで利用できます。コードベースを調査し、コードを生成し、コマンドを実行し、外部ツールに接続できます。すべてコマンドラインから行えるため、グラフィカルエディターに切り替えずに作業を続けられます。

このワークショップでは、Tailspin Toys で一連の作業を進めます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして、プロジェクトを確認します。
2. 星評価の変更を加え、ブラウザーで確認し、最初のプルリクエスト (PR) を手動でマージします。
3. フィルターの課題から始め、Plan モードで方針を決め、Autopilot モードで実装し、Interactive モードでレビューします。
4. リポジトリの指示を更新し、フィルターの作業に適用します。
5. 既存の `quality-checks` スキルを調整し、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) サーバーを追加し、ブラウザーでフィルターを確認します。
7. quality assurance (QA) カスタムエージェントを作成し、要件、テスト範囲、検証の証拠をレビューします。
8. フィルターの変更全体をレビューし、フィルターの PR で Agent Merge を使います。
9. コンテキスト、モデル、共有、任意のクラウドへの委任に使う便利なスラッシュコマンドを確認します。

ワークショップに集中できるよう、PR は 2 つ作成します。1 つ目は星評価、2 つ目は指示の更新、スキルの更新、QA プロファイル、テストを含むフィルター機能です。フィルターと品質ワークフローでは、1 つの会話とブランチを使い、各ツールを学ぶ間も作業を引き継げるようにします。

## 前提条件

このワークショップに参加する前に、次を準備してください。

- [ ] **Copilot Student、Pro、Pro+、Business、Enterprise** のいずれかの有効なプランがある GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナル / コマンド ライン操作の基本的な知識

> [!TIP]
> 有料プランがありませんか。認証済みの学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使用するエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれています。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使用している場合は、管理者が Copilot CLI を有効にしていることを確認してください。
